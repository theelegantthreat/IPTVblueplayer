# Contributing to IPTVblueplayer

Thanks for your interest in contributing! By participating in this
project you agree to abide by the guidelines below.

Reporting issues
- Search existing issues before opening a new one.
- Provide a clear title and description, steps to reproduce, expected vs actual behavior, device/emulator details, Android API level, and any relevant logs.

Feature requests
- Describe the user problem, proposed solution, and any UI/UX mockups if applicable.
- Label the request as `enhancement` when opening an issue.

Pull request process
1. Fork the repository and create a topic branch from `main`.
2. Keep changes in a single logical commit (or a small set of related commits).
3. Write a clear PR title and description explaining the change and why it is needed.
4. Add screenshots or recordings for UI changes.
5. Link the PR to any related issue.

Coding style
- This project uses Kotlin. Follow idiomatic Kotlin style and Android best practices.
- Use Android Jetpack libraries where appropriate.
- Keep code readable and well-documented. Prefer descriptive names over comments; add KDoc for public classes/methods.

Testing
- Manual testing on an emulator or physical device is sufficient for small changes.
- If adding significant logic, include unit tests where practical.

Commit messages
- Use concise, descriptive commit messages. Start with a short summary (<=50 chars) and an optional body.

Code review
- PRs will be reviewed and may request changes. Address feedback promptly and update the PR.

Small contributions
- Typos, README improvements, and documentation updates are welcome—no PR size requirement.

Contact
- If you're unsure how to start, open an issue and ask — maintainers will help guide you.

Thank you for contributing!
