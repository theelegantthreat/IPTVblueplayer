# IPTVblueplayer

A simple Android IPTV player written in Kotlin.

Copyright (C) 2026 <theelegantthreat>

Features
- Play IPTV streams (M3U, HLS)
- Simple, lightweight UI

Getting started

Prerequisites
- Android Studio (2022.3 or newer recommended)
- Android SDK (API level 21+)
- Gradle (handled by Android Studio)

Build and run
1. Clone the repository:

   git clone https://github.com/theelegantthreat/IPTVblueplayer.git
2. Open the project in Android Studio.
3. Let Gradle sync and download dependencies.
4. Run the app on an emulator or device.
